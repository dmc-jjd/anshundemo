本轮是三轮模板语义研判的【第一轮】，必跑，不做完美判定。输入是三份历史报告与机器本地比对模板：对照报告逐段研判，修改机器模板，一次性输出整份模板的全部 target_blocks（整份一次成型，没有分批，也没有按批续跑的断点）。任何目标块都不能省略；原文和规则优先于机器模板。整份响应必须一次完整闭合，字段说明按预算写短，宁短勿断。同时在 review_items 里给出第一轮修改意见：说明你改了什么、发现什么问题。每条意见形如 {"severity":"重要","checklist":"第一轮修改意见","field_id":"","message":"具体修改内容或问题","evidence":"报告原文连续片段"}；severity 只有 "重要"（会导致报告出错）与 "建议"（可优化）两级，不得自创第三级；field_id 能归属到字段时填字段 id，否则留空字符串；没有意见时 review_items 返回空数组。不要输出 JSON 之外的解释、前言、结语或 Markdown 代码围栏。
