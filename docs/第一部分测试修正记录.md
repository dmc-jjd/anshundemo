# 10 月报告第一部分：测试、修正意见、代码修改

## 测试范围与方法

- 对照原件：`2026年10月安顺市网络舆情分析报告.docx` 的第一大模块，含（一）至（四）四段、五张图和 TOP10 表。
- 数据来源：`安顺市委10月总数据.xlsx` 第三工作表、`安顺市委10月负面预警数据（已去重）.xlsx` 第三工作表。
- 重跑：`python scripts/audit_first_section.py`，再运行 `python scripts/test_first_section.py`。
- 数字按每个明确字段精确匹配；文字用去掉未填占位符后的字符序列相似度，仍单独列出未填槽位。该文字分数只是复现测试指标，不代表语义准确。

## 本轮修正

`app/export.py` 已将第一部分（二）的平台名称、八个计数及占比绑定到 `calculate_metrics` 工件，并修复第一部分（一）负面占比重复输出百分号。`app/config.py` 可读取本地 `.env`，`app/model_client.py` 根据目标输出结构提示模型；真实 DeepSeek 接口已经返回合格的工具选择。密钥不写入测试产物或日志。
