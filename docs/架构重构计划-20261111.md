# 报告工作台架构重构计划（v2 · 唯一权威）

> **本文件是唯一权威版本。**
> 取代 `docs/架构重构框架.md` 与 `docs/架构重构计划-20261111.md` 的早期版本；旧文档仅作历史记录，不再作为实施依据。
>
> 目标：**编排基座只做一次、长期稳定；加客户 = 加一个包，不改基座代码。**

## 0. 一页摘要

| 层 | 内容 |
|---|---|
| ④ 交付与接入层 | Web 工作台 · HTTP API（通用任务生命周期） |
| ③ 编排基座（客户无关） | 图编排 · 审校循环 · Agent 运行器 · 工具执行器 · 状态/工件存储 · 模型客户端 · **工具库** · **图表包** · **技能包** |
| ② 客户包（按客户/报告类型） | **客户报告模板**（含 charts / data_contract / vocabulary）· **客户 Agent 提示词** · **工具白名单** · 图表与技能引用 |
| ① 基础设施 | LangGraph · 模型 · SQLite · OOXML · 图表库 |

三条硬边界：

1. **客户包不含实现**。工具实现、图表渲染、技能检测代码全在基座。
2. **客户包只声明"用哪些"**。白名单管工具，`use:` 管图表与技能。
3. **基座代码不出现客户业务词**。`安顺`/`西秀`/`舆情调性`/`b40_analysis_paragraph`/`CLUSTER_TERMS` 等必须为 0 命中。

## 1. 职责边界

### ③ 编排基座

| 模块 | 职责 |
|---|---|
| 图编排引擎 | 读 `GraphSpec` 组图，不认识任何具体报告业务 |
| 审校循环引擎 | 轮次预算、路由、退修策略，角色由客户提示词包提供 |
| Agent 运行器 | 角色 + 提示词 + 输出 Schema → 一次模型调用 |
| 工具执行器 | `ToolSpec` 契约 + 白名单门禁 + 幂等 + 超时 + 冻结校验 |
| 工具库 | 客户无关的工具实现（取数、过滤、聚类、指标、图表、检索） |
| 图表包 | 图表族 + 样式枚举 + 数据绑定契约 + 渲染器 |
| 技能包 | 文风/去 AI 表达检测、来源绑定、校验规则 |
| 状态/工件存储 | 任务状态、内容寻址工件、事件流 |
| 模型客户端 | 鉴权、重试、错误分类、用量记账 |

### ② 客户包

| 资产 | 内容 | 性质 |
|---|---|---|
| 客户报告模板 | `blocks + fields + bindings + rules + charts + data_contract + vocabulary` | 业务资产 |
| 客户 Agent 提示词 | 角色职责/边界 + 各阶段提示词，带版本指纹 | 业务资产 |
| 工具白名单 | 允许调用的工具、阶段约束、调用预算 | 声明 |
| 图表/技能引用 | `charts.pack/use`、`skills.pack/use` | 声明 |

## 3. 工具白名单：清掉执行器里的业务硬编码

`app/tool_executor.py` 当前把客户规则写死在流程里，这是本次最大的技术债：

| 现位置 | 现写法 | 迁移后 |
|---|---|---|
| `tool_executor.py:46` | `search_historical_web`/`fetch_historical_page` 仅 `phase=='writing'` 且有 `fact_ref` | `tools.phases.writing` |
| `tool_executor.py:48` | `propose_vector_event_neighbors` 必须带 `keyword_candidates_ref` | 由 `arguments_schema.required` 表达，删特判 |
| `tool_executor.py:55-57` | `import_records`/`parse_report_document` 路径必须在任务输入内 | 通用「输入来源校验」，路径集合来自任务 |
| `tool_executor.py:58-59` | `filter_records` scope 白名单写死 | scope 枚举由 `arguments_schema` 提供 |
| `tool_executor.py:60-63` | writer 只读工具名单 + `writer_tool_calls>=80` | `tools.phases.writing` + `budgets.writing` |
| `tool_executor.py:64` | `mutates_facts` 冻结校验 | **保留**（通用契约） |

### 3.1 拒绝码（必须可审计）

| 场景 | error_code |
|---|---|
| 工具不在 `allow` | `tool_not_allowed` |
| 阶段不符 | `tool_phase_not_allowed` |
| 超预算 | `tool_budget_exceeded` |
| 冻结后调写类工具 | `frozen_facts`（沿用） |

每次拒绝写 `tool_policy_rejected` 事件（含 tool / phase / reason），便于回溯。

### 3.2 执行器目标

`tool_executor.py` 只认三样东西：`ToolSpec` 契约、`manifest` 白名单、任务状态。**代码内 0 业务词、0 客户名。**

## 7. 数据契约与词典（`data_contract` / `vocabulary`）

这两段不是新概念，是把 `app/tool.py` 里写死的客户口径**数据化**。

### 7.1 `data_contract`：这份报告认哪些列

现在 `tool.py:30` 写死：

```python
if '标题' not in header or '舆情调性' not in header:
    raise ValueError('missing_required_columns')
```

`tool.py:40` 还有一长串列名映射：`data.get('作者Id')`、`data.get('媒体环节')`、`data.get('媒体属性')`……

这是**客户表格的列名约定**。换客户 = 换这段映射，`import_records` 的搬运逻辑不需要改。

```json
"data_contract": {
  "required_columns": ["标题", "舆情调性"],
  "column_map": {
    "标题": "title", "舆情调性": "sentiment", "发布时间": "published",
    "来源信息": "source", "作者": "author", "作者Id": "source_id",
    "事件分类": "category", "网址": "url", "媒体环节": "platform",
    "媒体属性": "media_attribute", "媒体级别": "media_level",
    "是否预警": "warning", "摘要": "summary"
  },
  "sheet_index": 3
}
```

### 7.2 `vocabulary`：这份报告按什么词归口

| 现位置 | 写死内容 |
|---|---|
| `tool.py:62` | 8 个区县：`{'西秀区':['西秀区'], '镇宁自治县':['镇宁'], …}` |
| `tool.py:168-181` | `CLUSTER_TERMS` 12 类事件：`{'交通管理':['交通','公交','停车'], …}` |

```json
"vocabulary": {
  "localities": {
    "西秀区": ["西秀区"], "平坝区": ["平坝区"], "普定县": ["普定县"],
    "镇宁自治县": ["镇宁"], "关岭自治县": ["关岭"], "紫云自治县": ["紫云"],
    "黄果树旅游区": ["黄果树"], "安顺经开区": ["经开区", "开发区"]
  },
  "cluster_terms": {
    "交通管理": ["交通", "公交", "停车", "道路", "司机", "车辆", "驾考"],
    "文化旅游": ["景区", "游客", "黄果树", "旅游", "门票", "民宿"]
  }
}
```

### 7.3 为什么算「模板」而不算「配置」

它们定义的是**这份报告的数据长什么样、按什么口径归类**，与 `blocks/fields/bindings/rules` 属于同一类事实。因此并入 `template.json` 不破坏「客户包只留模板 + 提示词」。

附带收益：现在改 `CLUSTER_TERMS` 一个词要改 `.py` 并重启服务；数据化后改词只改数据，且分类口径可随模板版本一起审计。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **无版本控制** | 改坏无法回退 | P0 全量备份 + 每阶段结束后再备份一次 |
| 一次性搬迁改爆调用点 | 报告链路中断 | 旧模块保留 re-export 薄壳，调用方零改动 |
| 图表重绘与原图不一致 | 交付物对比失败 | P0 像素级快照 + 逐字节比对 |
| 提示词外置后指纹变化 | 机器稿全部重写、费用上升 | 外置保持逐字节不变 |
| 白名单过严导致工具被拒 | 任务卡在 `needs_review` | 初版 `allow` 取「当前实际调用集合」，先等价再收紧 |
| 词典数据化后口径漂移 | 事件分类结果变化 | 迁移后全量对照，分类结果 diff 必须为空 |
| 服务在跑 | 重构触碰运行中任务 | 重构期间不重启 8899 服务；改动先落文件，验收后再决定重启 |
