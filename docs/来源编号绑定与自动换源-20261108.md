# 来源编号绑定与不可读页换源（2026-11-08）

Writer提示词统一在 app/agent.py。模型收到整数资料编号，程序维护编号与真实来源ref的目录，返回后绑定，保存 writer_source_catalog 审计。工具新增资料由程序登记；统计数值、正文不作为来源编号转换。

引用容错：有效数字字符串或完全匹配已登记ref可精确转换；未知编号、猜测ID不绑定。结构化写作首次生成后最多两次只修复引用，不重写已生成正文。三次仍失败，保留合规候选正文到 writer_pending_sources，自动流程结束后在“查看报告与缺失项”和“双审核与人工终审”展示“正文已生成，引用待核对”。可直接编辑并点击“人工核对后采用这段正文”，仅本地保存，无模型回流。待核对内容不伪装为已验证终稿；最终审核前仍需人工采用。退修失败保留上一版有效稿；旧逐槽路径保留候选文字供人工补填。

网页读取识别验证码、安全验证、登录/订阅、访问拦截、失效和空页面。失败URL记入当前任务，相同冻结数据内跨轮跳过；可读页优先复用。读取失败后自动换同次搜索候选，优先官方来源；候选不足最多一次补搜。每次读取最多3次尝试，每期最多12次抓取。实际替换页面的URL和来源单独记录，不借用原页面标题/日期。全失败时返回可读的失败原因及季节风险候选提示，不伪造本地历史证据。运行动态简要展示，完整来源与原因进日志；风险依据页可展开已跳过来源。
