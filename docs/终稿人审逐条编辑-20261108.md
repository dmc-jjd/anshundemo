# 终稿人审：编号、保留与原句编辑

本轮修复按钮被强制核查说明拦截的问题。核查说明改为选填，点击“已核对，保留当前内容”即可记录人工决定；没有补充说明时，审计记录为“人工已核对，保留当前内容”。

每条意见有独立编号，处理后不将后续编号前移。引用原文直接显示为编辑框，点击“保存本处修改并覆盖终稿”后仅替换选中原句，并处理该条意见；同字段其他意见继续保留。工作建议数组只替换对应段落中的命中位置，保留其他句子、段落、字段和图表。重复原句需选择覆盖位置，旧稿哈希或变化的位置不会被误写；已经变化的引文可展开当前完整内容核对，并使用整段修订。

逐条保存刷新窗口时，其他意见中尚未提交的输入会保留。整段修订仍保留作通篇调整入口。人工操作不调用模型、不自动终审。

实现：app/static/writing-review.js、app/main.py、app/writing_review.py、app/reviewers.py。新接口 POST /api/tasks/{task_id}/writing-review/{issue_id}/edit，提交当前稿哈希、替换文字及精确位置。Word导出使用保存后的同一稿件。

验证：逐条编辑与图流程18项通过，已有人工补全/报告参数5项通过，共23项相关测试。隔离浏览器验证空说明保留、稳定编号、逐句覆盖、其他未提交输入保留、其他段落和字段不变、Word导出包含新文字；新增模型请求0、页面错误0。生产页面只读核验9条编号意见及9个逐条编辑框，实际任务仍为revision234，draft_ref保持，未改动用户已保存结果。
