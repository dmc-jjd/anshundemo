# 语义分类与去重解耦实施计划

用户已明确要求直接实现：BGE 分类头先分类，置信度达到 0.75 采用；其余交给大模型，明确 uncertain 才交人工。

**方案：** 分类使用独立的语义分类执行器。去重开启时按最终事件分类；去重关闭时按原始记录分类，不创建事件归并产物。两条路径共用阈值、模型调用、校验、审计和断点。现有人工覆盖优先保留。

**部署：** 支持现有远程 BGE 契约及独立 Python 环境中的本地编码器+joblib 分类头。路径和凭据放部署配置，客户包只声明能力和阈值。模型的额外类别不能直接进入客户模板的类别体系，须交 LLM 复判。
