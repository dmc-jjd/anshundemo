# 任务删除与提示词卡片 Implementation Plan

**Goal:** 审核模块任务卡支持二次确认后硬删除；模板页独立展示客户包提示词生成/更新时间、适用模板 ID 及适配状态。
**Architecture:** 复用模板任务删除入口，新增数据任务删除入口和框架无关服务。提示词内容保持包共享，以有效 bundle 摘要校验适配元数据；旧记录不推定已适配。UI 沿用现有卡片和确认框。
**Tech Stack:** FastAPI / SQLite / 原生 JavaScript / pytest / Chrome CDP。
**Spec:** 用户已选择独立提示词卡片；不更新提示词正文、不代跑报告，实际任务不用于删除验收。

- [x] 先写任务硬删除和提示词适配状态失败测试：运行中拒绝、引用保护、数据库/文件删除、摘要过期、无记录、包隔离。
- [x] 实现任务删除：任务/事件/审核草稿/幂等声明/独占工件及导出文件清除；保留共享上传和其他任务引用工件；复用模板引用确认逻辑。
- [x] 实现提示词状态读取和后续适配记录工具：记录真实时间、已确认模板 ID、有效提示词摘要；修改提示词后旧适配记录显示待复核。
- [x] 新增任务卡删除按钮（不嵌套按钮）、取消不发送 DELETE，已选任务删除后清空详情；新增提示词卡片及模板状态措辞。
- [x] 同步建包 skill 的适配记录交接；定向离线测试、合成删除浏览器回归、真实工作台只读展示验证、重启8765。

约束：沿用优化分支和当前未提交编辑；无真实任务删除、无新提示词撰写、无自动确认。已确认模板仅更新外部适配记录。历史生成时间缺失显示未记录，文件修改时间单列。适配状态是提示信息，不扩大为新的生成阻断门禁。
