# 字段关联与龙川写作口径实施计划

Goal: 修复候选选材、媒体机构家数和跨字段写作断链；确认模板与已冻结任务不改写。

Architecture: 客户包提供按模板 ID 选择的 writing_contracts.yaml；基座解析通用关联组与统计参数。候选模板允许用户审阅、编辑关联组；写作成组生成并记录契约快照，双审获得同一组上下文。

Tech Stack: Python/FastAPI/Pydantic、YAML、原生 JavaScript。

- [x] 契约模型与测试：字段角色、分组冲突、模板隔离、契约摘要与任务快照。
- [x] 计算测试与实现：候选正面/地域/业务条件；媒体机构别名与未解析身份显式阻断；保留原始传播计数。
- [x] 龙川配置：绑定新模板，保留旧版兼容，后续新任务去重开启，不改已有快照。
- [x] Writer 成组调用：全部关联字段、共同材料、已有值、完整模板片段；同组失败原子处理与重试。
- [x] 双审与退修：传入契约及整组上下文；保护程序统计；逻辑替换需来源支撑，不无条件锁死机器旧日期/列表条数。
- [x] 模板确认预览：显示关联组、字段角色；未确认候选可保存，确认模板只读；建包 skill 交付规则。
- [x] 回归验证与只读业务核验；完成提示词适配记录、技术交接与业务验收说明，不自动运行付费模型。

Ruling: 用户已批准实施，不另设设计审批；当前脏工作区包含既有交付，直接增量修改，不切换或清理。客户业务规则放包内，基座仅添加通用能力。
Ruling: 历史模板内按账号统计的描述保持原样；新写作契约显式展示覆盖后的机构口径，并在任务创建时快照，不静默修改已建任务。

业务验收由用户执行，技术完成不等于报告质量已验收。媒体机构目录与层级冲突详见 verification.md。
