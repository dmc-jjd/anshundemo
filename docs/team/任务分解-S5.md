1. `structured_writer.py:104-106`：`fingerprint=prompt_fingerprint(profile)`；`same_prompts = previous_fingerprint==fingerprint`。不相等 → 走重写分支 → **所有字段的机器稿全部重生成**（真金白银）。
2. `structured_writer.py:145-146` + `:45-52`：`field_prompt_fingerprint` 逐字段落 `writer_field_prompt_fingerprints`；不等即单字段重写。

## 3. 必须回答的四个设计问题

### 3.1 用 Python 三引号字符串在 `.py` ↔ `.md` 之间往返，哪些地方可能丢字节？

先给结论：**当前的 32 条文本本身没有一处危险构造**（§0.4：无 `\r`、无 TAB、无 `\`、无 `'''`/`"""`、无 BOM/NBSP、无行尾空白、无重复值）。
危险全部来自**落盘/回读的工具链**，不是文本内容。逐条列：

| # | 丢失点 | 机制（本机实测或代码事实） | 谁会触发 | 检测手段 |
|---|---|---|---|---|
| **H1** | **结尾换行** | 32 条**全部不以 `\n` 结尾**；而 `.md` 文件按惯例要以 LF 收尾，编辑器/git/`echo` 都会补一个 | 加载时若不剥，每条都多 1 字节 → 26 条多行文本的 prompt 全部 +1；`prompt_fingerprint` 全变 | ① 归一口径：文件正文 = 提示词 + **恰好一个** LF，加载剥一个（无则不剥）；② `G-PROMPTS`；③ `test_no_prompt_ends_with_newline` 钉住「提示词不得以 LF 结尾」使规则无歧义 |
| **H2** | **开头换行** | 2 条（`writer.analysis_output`、`template_analyst.charts`）首字符就是 `\n`——那是 `'''` 换行写法留下的**真实字节**，不是排版 | 任何 trim / prettier / markdownlint / "删除空行" / `text.strip()` 都会吃掉它 | ① `G-PROMPTS`（实测探针 FAIL ✅）；② `test_prompt_shape_oddities` 显式断言这两条 `startswith('\n')` |
| **H3** | **首行前导空格** | `event_judge.repair` = `' 修正前次覆盖或分组错误，返回完整结果。'`，首字符是半角空格 | 编辑器 trim-trailing-whitespace 一般不动行首，但 `strip()` / "去除多余空白" 会 | ① `G-PROMPTS`（实测探针 FAIL ✅）；② 同一条 shape 测试断言 `value[0]==' '` 且 `value != value.strip()` |
| **H4** | **行尾符 CRLF** | `Path.write_text` 在 Windows 把 `\n` 写成 `\r\n`（**实测** `b'A\r\nB'`）；`Path.read_text` 又把它**静默翻回** `\n`（**实测**）→ 双向掩盖。Python 3.13 的 `read_text` 虽已有 `newline=` 参数，但默认仍是 `None`（通用换行） | 任何人用 `write_text` 落盘、或用 `read_text` 读盘 | ① **落盘 `write_bytes`、回读 `read_bytes().decode('utf-8')`**（本方案），CRLF 立刻以多出的 `\r` 现形；② `G-PROMPTS`（实测探针 FAIL ✅） |
| **H5** | **BOM** | `read_text(encoding='utf-8')` 会**保留** `'\ufeff'`（实测）；`utf-8-sig` 会**静默吃掉**（实测）。Windows PowerShell 5.1 的 `Out-File`/`Set-Content` 默认写 BOM | 落盘用 PowerShell 重定向、或回读用 `utf-8-sig` | ① 落盘一律 `write_bytes`/Python 侧 `yaml.safe_dump(...).encode('utf-8')`；② 回读**禁止** `utf-8-sig`（与 S4 §0.3① 同纪律）；③ `G-PROMPTS`（实测探针 FAIL ✅） |
| **H6** | **编码错位（GBK/ANSI）** | Windows PowerShell 5.1 的 `Set-Content`/`Out-File` 不带 `-Encoding` 时按 ANSI(GBK) 写；`>` 重定向同理 | 用 PowerShell 直接写中文提示词 | ① 落盘不用 PowerShell 重定向；② 回读 `decode('utf-8')` 抛 `UnicodeDecodeError` → `PromptBundleError('prompt_not_utf8:<key>')` **fail fast**，不会带病运行 |
| **H7** | **YAML 折行（只威胁 `roles.yaml`/`index.yaml`）** | `yaml.safe_dump` 默认 `width=80`，长标量会被拆行；朴素标量折行时**断点处的换行被折成一个空格**，连续空格会被压掉 | 只用默认参数 dump | ① **必须 `width=10**6`**（本预演即如此，实测严格相等）；② 角色/策略串**不许**用 YAML 折叠标量（folded）或字面块标量（literal block）——前者把换行折成空格，后者保留尾换行；③ `G-PROMPTS` 的 `AGENT_DEFINITIONS`/`TEMPLATE_POLICY` part 哈希兜底 |
| **H8** | **数字/布尔型标量被 YAML 重解析**（`index.yaml`） | `min_items: 4` 存成 int 没问题；但若某天出现 `structure: 15` 或 `question_policy: yes/no/on/null`，PyYAML 会解析成 int/bool/None | 未来编辑者手写 yaml | ① `test_template_policy_types_and_order` 逐项断言 `type(...) is int`/`str`；② 规则：**任何会被 PyYAML 解析成非 `str` 的字面量必须加引号** |
| **H9** | **空 dict 被降级成 `None`**（`index.yaml`） | `report_prompt_profiles: {anshun_monthly: {}}` 若手写成 `anshun_monthly:`（冒号后留空），PyYAML 解析为 `None` → `get_prompt` 里 `key in overrides` 直接 `TypeError: argument of type 'NoneType' is not iterable` | 手写 yaml | ① 生成用 `safe_dump`（会写 `{}`）；② 加载器**显式校验**每个 profile 值必须是 `dict`（`prompt_profile_invalid:<name>`） |
| **H10** | **统一空白/全角转换** | 有 1 条纯 ASCII（`data_processor.next_tool`），其余含全角 `，；：（）—`；任何"全角转半角"或"中文标点规范化"都会改字节 | 格式化工具/人工"润色" | `G-PROMPTS`（`default=str` 让所有值进哈希）；此外 `ARP` 层面无他法——**只能靠门禁** |

**检测手段的层次（从硬到软）**：

1. **G-PROMPTS 哈希**（唯一充分判据，覆盖 H1–H10 全部）；
2. **G-PROMPTS-ORDER**（补 H7 的键序盲区，§0.8 预演已证明必要）；
3. **6 条形状断言**（H2/H3 这类"语义上合法但极易被顺手改"的点，给可读归因）：`test_prompt_shape_oddities`、`test_no_prompt_ends_with_newline`；
4. **负向探针矩阵**（§0.8 实测的那 8 个探针写进 `tests/test_s5_prompt_gate.py` 的 1 个用例，防"门禁自己失效"）：故意造 CRLF/BOM/剥首行/双尾换行 4 种脏文件，断言门禁必须 FAIL；
5. **读盘纪律**（`read_bytes().decode('utf-8')`）：让 H4/H5 从"被掩盖"变成"立刻红"。

> 一句话：**文本本身没有危险字符，危险全在"用什么 IO 把它写出去、又用什么 IO 把它读回来"**。
> 所以本文强制 `write_bytes`/`read_bytes`，并让门禁对"看不见的规范化"（CRLF/BOM/trim）全部红灯。

### 3.2 `AGENT_PROMPTS` 的键与提示词文件名的映射规则？

**规则（总函数、双射、可机械反查）**：

```text
key ──────────────►  <manifest.prompts>/agent/<key>.md        （键逐字保留，含 "."，不改写、不转义、不分组、不嵌套）
<key>.md ─────────►  <去掉末尾 ".md">                          （反查唯一）
```

- **一文件一提示词**：32 键 → 32 文件，文件名与键**逐字对应**（例：`writer.slot.base` → `agent/writer.slot.base.md`）。
  不做 `writer/slot/base.md` 这种按前缀分组：分组需要再多一条"点号怎么变斜杠"的规则，而它换不来任何门禁收益（`G-PROMPTS` 只看内容，不看路径）。
- **权威映射在 `index.yaml` 的 `agent_prompts:` 段**，而不是"扫目录猜键"：
  ```yaml
  agent_prompts:
    style.application: agent/style.application.md
    format_reviewer.review: agent/format_reviewer.review.md
    ...
  ```
  理由三条：① 目录里多一个 `.md` 不会被静默加载（`test_no_stray_prompt_files` 断言 `set(agent/*.md 文件名去后缀) == set(index 键)`）；② 少了文件是**显式报错** `prompt_missing:<key>` 而不是 `KeyError`；③ 第二客户包可以给同一个键换文件名而不用改代码（S7 直接受益）。
- **键集合即契约**：`index.yaml` 的键集必须与 `get_prompt` 认识的键集一致。`get_prompt` 的 `unknown_agent_prompt:` 错误语义**保持不变**（仍然在调用期抛，不提前到 import 期）。
- 允许的字符集：`[a-z_.]` + 中划线（现状 32 键全部满足：小写字母、下划线、点号）。键里不含 `/`、`\`、空格、`:`——`test_prompt_keys_are_path_safe` 断言，防将来有人用中文/斜杠做键把路径拼出去。

### 3.3 `REPORT_PROMPT_PROFILES` / `TEMPLATE_POLICY` 的嵌套结构如何在 yaml 里表达而不改变语义？

四个硬要求 + 对应表达：

| # | 语义要求 | YAML 表达 | 为什么这样才不丢语义 |
|---|---|---|---|
| 1 | **键序是语义**（仅对 `TEMPLATE_POLICY`：F5 证明它经 `json.dumps(不排序)` 进模型消息） | 用 `safe_dump(..., sort_keys=False)` 按原顺序写；加载用 `safe_load`（PyYAML 6.0.3 → 普通 `dict`，**保插入序**） | 若 dump 时 `sort_keys=True`（默认）→ 键变 abc 序 → 发给模型的 JSON 文本变 → 模型行为变。**这是本 S5 唯一"看起来无害实际改行为"的坑**，靠 `G-PROMPTS-ORDER` + `test_template_policy_order_is_stable` 双钉 |
| 2 | **嵌套层级不得塌陷** | 直接写嵌套 mapping：`recommendations: {min_items: 4, max_items: 5, structure: …}`、`top10: {…}`、`review_controls: {…}` | 三个子 dict 各自是独立 mapping，不合并、不摊平。`G-PROMPTS` 的 `TEMPLATE_POLICY` part 哈希会抓住任何层级变化 |
| 3 | **int 必须是 int**（`4/5/15/35`） | 裸写 `min_items: 4`（**不加引号**） | PyYAML 解析成 `int`，与现状 `isinstance(x,int)` 一致。若写成 `'4'` → `TEMPLATE_POLICY` 全等断言立刻红（`{'4'} != {4}`） |
| 4 | **空 dict 必须是空 dict**（`REPORT_PROMPT_PROFILES = {'anshun_monthly': {}}`） | 显式写 `anshun_monthly: {}` | 写成 `anshun_monthly:` → `None` → `get_prompt` 内 `key in None` 抛 `TypeError`（H9）。加载器再加一道 `isinstance(overrides, dict)` 校验，双保险 |
| 5 | **`DEFAULT_PROMPT_PROFILE` 必须在 profiles 键集内** | `default_prompt_profile: anshun_monthly` | 加载器校验 `default in profiles`，否则 `prompt_profile()` 的 `unknown_writer_prompt_profile` 会在运行期才炸 |

`roles.yaml` 的形状（每个角色恰好 4 键，`role_id` 与 map 键同值——沿用现状把 `role_id` 写进字段，保持一致）：

```yaml
historical_researcher:
  responsibility: 先用模型知识比较5—8类未来风险，按需核实地方事实，研究目标5类历史、季节或地方活动合格选题，至少4类方可完成研究
  boundary: 模型知识只用于候选和条件推演；具体地方事实须有来源，不把一般常识说成本地高发；不替用户确认事实
  output: 5—8类候选比较、目标5类且至少4类有依据的未来风险及其依据性质
```

**安全性实测**：10 个角色的 30 个字段**全部 0 处 ASCII 冒号、0 处 `#`、0 处首尾空白、0 处以 YAML 指示符开头**（`- ? : , [ ] { } & * ! | > % @ \`` 与引号），所以**朴素标量（plain scalar）安全**，不需要给它们加引号。`TEMPLATE_POLICY` 的 6 个字符串同理。

> 但**规则仍要写死**：将来任何人新增一条含 `: `（冒号+空格）、` #`、或以指示符开头的角色/策略文本，必须**加双引号**（`safe_dump` 会自动加，手写者必须知道）。
> 这条不靠自觉——`G-PROMPTS` 与 `roles()` 全等断言会抓住"引用没加导致 YAML 解析成嵌套结构"的后果。

### 3.4 加载失败（文件缺失/编码错）应 fail fast 还是回落？

**结论：fail fast，且失败点放在 `configure()`（= `import app` 期）。** 理由四条，前两条是决定性的：

1. **回落会把刚拆掉的"第二份真相"装回去**。S5 的全部意义是让提示词只有 `packages/**/prompts/` 一个家。
   若加载失败就退回 `app/agent.py` 里的内置副本，`agent.py` 必须继续存着 32 条原文——那是**双份真相 + 静默分叉**，比不改更糟。
2. **回落会让门禁在一份残缺的包上照样变绿**。`G-PROMPTS` 的判据是"加载结果 == 基线"。如果缺 3 个文件时加载器回落到内置值，
   哈希照样等于基线 → **门禁失去意义**。fail fast 是让 `G-PROMPTS` 保持"充分判据"的前提。
3. **消费者的性质决定了"带病运行"代价极高**。提示词是**发给模型的指令**：空串或半截提示词不会报错，只会产出"看起来像样但错"的公文，再经审查/退修/生成 Word 全链路放大，最后靠人工发现。宁可起不来。
4. **同仓已有先例，保持一致最省认知**：`core/charts/registry.py:32` 与 `core/skills/registry.py` 都是 `RuntimeError('package_not_configured')` 且**明确拒绝静默回落**；S4 D3 已裁决「指纹校验放 `configure()` 期预热，失败时机从首次检测提前到 `import app`」。S5 沿用同一姿势。

**边界（两处必须区分，不要一刀切）**：

| 情况 | 处置 | 理由 |
|---|---|---|
| `index.yaml`/`roles.yaml`/`*.md` **缺失、不可读、非 UTF-8、结构不符**（键缺、profile 值非 dict、default 不在 profiles、角色字段不是恰好 3 个 str） | **`PromptBundleError`（`RuntimeError` 子类）在 `configure()` 期抛出** | 属于"包坏了"，不是运行期可恢复条件 |
| 提示词本身是**空串/纯空白** | **保持现状**：仍由 `get_prompt()` 在**调用期**抛 `ValueError('invalid_agent_prompt:<key>')` | 现状语义如此（`app/agent.py:193-194`）。若搬到 import 期，等于**顺手改了错误时机**，会把一个"只有用到该键才炸"的错误变成"整个应用起不来"。S5 是搬迁，不许附带行为变更 |

`PromptBundleError` 的命名与 `core/manifest.py:18` 的 `PackageError` 同构（都是 `RuntimeError` 子类 + `xxx_yyy:detail` 消息格式），便于日志与用户提示归因。

     ```python
       - 角色职责与边界   → `<prompts>/roles.yaml`

     from pathlib import Path
     from typing import Any

     import yaml

     from core.manifest import load_manifest


     class PromptBundleError(RuntimeError):

     _INDEX_KEYS = ('agent_prompts', 'template_policy', 'report_prompt_profiles', 'default_prompt_profile')
     _ROLE_FIELDS = ('responsibility', 'boundary', 'output')
     _package_dir: Path | None = None


     def configure(package_dir: Path) -> None:
         """绑定客户包并预热整包（读盘 + 结构校验），包不对就在 import 期炸。"""

     def _require_configured() -> Path:

     def _text(path: Path, label: str) -> str:
         """按字节读再解码：禁通用换行翻译、禁 BOM 消化（见模块 docstring 口径 1）。"""

             return path.read_bytes().decode('utf-8')
         except OSError as exc:
             raise PromptBundleError('prompt_unreadable:' + label) from exc
         except UnicodeDecodeError as exc:
             raise PromptBundleError('prompt_not_utf8:' + label) from exc

         try:
             return yaml.safe_load(_text(path, label))
         except yaml.YAMLError as exc:
             raise PromptBundleError('prompt_yaml_invalid:' + label) from exc

     def _bundle(package_dir: Path) -> dict[str, Any]:
         base = Path(package_dir) / load_manifest(package_dir).prompts
         index = _yaml(base / 'index.yaml', 'index.yaml')
         if not isinstance(index, dict):
             raise PromptBundleError('prompt_yaml_invalid:index.yaml')
         missing = [key for key in _INDEX_KEYS if key not in index]
         if missing:
             raise PromptBundleError('prompt_index_missing_keys:' + ','.join(missing))
         declared = index['agent_prompts']
         if not isinstance(declared, dict) or not declared:
             raise PromptBundleError('prompt_index_invalid:agent_prompts')
         prompts: dict[str, str] = {}
         for key, rel in declared.items():
             if not isinstance(key, str) or not isinstance(rel, str):
                 raise PromptBundleError('prompt_index_invalid:agent_prompts')
             text = _text(base / rel, key)
             prompts[key] = text[:-1] if text.endswith('\n') else text
         roles = _yaml(base / 'roles.yaml', 'roles.yaml')
         if not isinstance(roles, dict) or not roles:
             raise PromptBundleError('prompt_roles_invalid:roles.yaml')
         for role_id, spec in roles.items():
             if not isinstance(spec, dict) or set(spec) != set(_ROLE_FIELDS):
                 raise PromptBundleError('prompt_role_invalid:' + str(role_id))
             if not all(isinstance(spec[field], str) for field in _ROLE_FIELDS):
                 raise PromptBundleError('prompt_role_invalid:' + str(role_id))
         policy = index['template_policy']
         if not isinstance(policy, dict):
             raise PromptBundleError('prompt_index_invalid:template_policy')
         profiles = index['report_prompt_profiles']
         if not isinstance(profiles, dict) or not profiles:
             raise PromptBundleError('prompt_index_invalid:report_prompt_profiles')
         for name, overrides in profiles.items():
             if not isinstance(overrides, dict):
                 raise PromptBundleError('prompt_profile_invalid:' + str(name))
         default = index['default_prompt_profile']
         if not isinstance(default, str) or default not in profiles:
             raise PromptBundleError('prompt_profile_invalid:default_prompt_profile')
         return {'prompts': prompts, 'roles': roles, 'template_policy': policy,
                 'report_profiles': profiles, 'default_profile': default}


     def prompts() -> dict[str, str]:
         """键 → 提示词全文（副本；键序 = index.yaml 声明序）。"""
         return dict(_bundle(_require_configured())['prompts'])


     def roles() -> dict[str, dict[str, str]]:
         """角色 id → {responsibility, boundary, output}（副本；顺序 = roles.yaml 声明序）。"""
         return {role_id: dict(spec) for role_id, spec in _bundle(_require_configured())['roles'].items()}


     def template_policy() -> dict[str, Any]:
         """模板分析策略（深拷贝：键序即语义，见 app/model_client.py 的非排序 json.dumps）。"""
         return deepcopy(_bundle(_require_configured())['template_policy'])


     def report_profiles() -> dict[str, dict[str, str]]:
         """报告提示词 profile → 覆盖项（深拷贝；空 profile 保持 `{}` 而不是 `None`）。"""
         return deepcopy(_bundle(_require_configured())['report_profiles'])


     def default_profile() -> str:
         """默认 profile 名（必须 ∈ report_profiles()，加载期已校验）。"""
         return _bundle(_require_configured())['default_profile']
     ```

  ```python
  """提示词薄壳：客户注入点 + 既有公开名。文本与角色全部在 `packages/<pkg>/prompts/`。

  `core/prompts/registry.py` 负责读盘与结构校验（`app/__init__.py` 在首次 import 时 configure 一次）；
  本模块只做三件事：把 4 个数据对象绑成同名全局、把 5 个旧文本常量降级为别名、保留 3 个策略函数。
  这三个函数的函数体自 S4 起一字未改——39 个 `get_prompt` 调用点全靠它们。
  """
  from dataclasses import dataclass
  from core.prompts import registry as _registry

  @dataclass(frozen=True)
  class AgentDefinition:
      role_id: str
      responsibility: str
      boundary: str
      output: str

  # 角色定义：状态数据 → frozen dataclass（`model_client.py:73` 用属性访问）
  AGENT_DEFINITIONS = {role_id: AgentDefinition(role_id, spec['responsibility'], spec['boundary'], spec['output'])
                       for role_id, spec in _registry.roles().items()}

  # 提示词与结构化策略：唯一的家在客户包；这里只持有加载结果的副本
  AGENT_PROMPTS = _registry.prompts()
  TEMPLATE_POLICY = _registry.template_policy()
  REPORT_PROMPT_PROFILES = _registry.report_profiles()
  DEFAULT_PROMPT_PROFILE = _registry.default_profile()

  # 旧文本常量保留为别名（全仓 0 消费，但保留零成本；见 docs/team/任务分解-S5.md §7 D2）
  RISK_COMPARISON_PROMPT = AGENT_PROMPTS['historical_researcher.plan']
  RESEARCH_PROMPT = AGENT_PROMPTS['historical_researcher.research']
  ANALYSIS_PROMPT = AGENT_PROMPTS['writer.analysis']
  OUTLOOK_PROMPT = AGENT_PROMPTS['writer.outlook']
  TEMPLATE_INSTRUCTION = AGENT_PROMPTS['template_analyst.template']

  def prompt_profile(task_metadata=None, template=None):
      metadata = task_metadata or {}
      template = template or {}
      selected = metadata.get('writer_prompt_profile') or template.get('metadata', {}).get('writer_prompt_profile') or DEFAULT_PROMPT_PROFILE
      if selected not in REPORT_PROMPT_PROFILES:
          raise ValueError('unknown_writer_prompt_profile:' + str(selected))
      return selected

  def get_prompt(key, profile=DEFAULT_PROMPT_PROFILE):
      if profile not in REPORT_PROMPT_PROFILES:
          raise ValueError('unknown_writer_prompt_profile:' + str(profile))
      if key not in AGENT_PROMPTS:
          raise KeyError('unknown_agent_prompt:' + key)
      overrides = REPORT_PROMPT_PROFILES[profile]
      value = overrides[key] if key in overrides else AGENT_PROMPTS[key]
      if not isinstance(value,str) or not value.strip():
          raise ValueError('invalid_agent_prompt:' + key)
      return value

  def prompt_fingerprint(profile=DEFAULT_PROMPT_PROFILE, prefixes=('writer.', 'historical_researcher.')):
      """Machine prose is regenerated when its chosen writing instructions change."""
      import hashlib,json
      prompts={key:get_prompt(key,profile) for key in AGENT_PROMPTS if key.startswith(prefixes)}
      return hashlib.sha256(json.dumps(prompts,ensure_ascii=False,sort_keys=True).encode()).hexdigest()
  ```

4. **`prompts/` 目录的寻址已数据化，但"哪个包"仍是硬编码**：`app/config.py` 里 `PACKAGE = 'anshun_monthly'` 是常量，`app/__init__.py` 据此 configure。S7 第二客户包时，这条链要能按任务/环境切换——S5 没动它（动了就是行为变更）。
5. **`.md` 后缀的语义陷阱**：`packages/anshun_monthly/prompts/agent/*.md` 是**数据**，不是给人读的文档。任何"文档格式化"（prettier、markdownlint、中文标点规范化、trim trailing whitespace）都会改字节。建议在 handoff 里给**新人/新 agent** 一句显式警告；若团队后续引入 pre-commit 格式化，必须把该目录加进 ignore（`design-pages/` 之外唯一一个"看起来是文档其实是数据"的目录）。
6. **仓库没有 `.gitattributes`**（实测缺失）：意味着 `*.md` 的换行由 `core.autocrlf` 决定。S5 的加载器用 `read_bytes` 后**任何 CRLF 都会立刻红**（这是好事：不会被掩盖）。若将来有人在 Windows 上用 `core.autocrlf=true` 提交，门禁会红——届时正确的处置是加 `.gitattributes`（`prompts/**/*.md -text` 或 `text eol=lf`），**不是**调基线。本文档未建议现在加（避免为一次性风险改动全仓 git 行为）。
7. **`gate_prompts.py` 与 `gate_skill.py` 的 `--record` 都是"破坏性门禁"**：基线文件一旦被覆盖，整个阶段的证据链作废。S5 之后若有人新增提示词（例如给新角色加一条），流程应是「先改提示词 → 跑门禁看到红 → **显式**重录基线并在 handoff 写明"机器稿会重写"」，而不是"红就重录"。
8. **`AGENT_PROMPTS` 的键集合现在是 client-package 契约**：`index.yaml` 的键集 = `get_prompt` 认识的键集。S6/S7 若要把某个 prompt key 改成别的名字，需要同时改 `packages/**/prompts/index.yaml` 与文件名，且**调用点也要改**（`get_prompt('writer.outlook')` 那 39 处）。目前没有任何机制防止"键改名但调用点漏改"——`get_prompt` 会在调用期抛 `unknown_agent_prompt`，这只能兜住用到的键。
