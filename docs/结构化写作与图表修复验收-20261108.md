## 实现

- `app/frozen_report.py`：冻结版本的明确统计定义、口径、分母、参数和分页材料查询。数值由程序运算；期号和成文日期必须显式提供。类别与属地按已确认事件，TOP10按负面且预警的事件内原始记录数，二者分开。
- `app/writer_tools.py`：注册 `frozen_statistics`、`query_frozen_materials`、`plot_frozen_chart`。Writer 可通过原生工具协议查询真实材料和计算，绘图使用 Matplotlib Agg。白名单不包含导入、合并、分类或任意代码执行。
- `app/model_client.py`：处理 assistant/tool_calls/tool 返回，限制轮次，保存无凭证的请求与响应工件；Writer 关闭推理模式，避免输出预算被思考耗尽。
- `app/structured_writer.py`：当前模板的确定计算定义；新字段可由模型选择受 Schema 约束的计算计划。只发送紧凑统计、字段语义和针对当前槽位的原文梗概。每块最多3轮纠错，失败继续后续块；人工文字保留且不再次研判。300–500字研判段同时受提示词、返回 Schema 和本地长度检查约束。
- `app/structured_template.py`、`app/export.py`：在原 Word 图位写入新的图像关系和PNG，保留图形位置；缺图时草稿保留标记，终稿阻断。图4、图5的事件统计单位改为“件”。稿件哈希包含图表引用；导出检查图表与事实版本匹配。
- `app/writing_review.py`、`app/main.py`、`app/static/app.js`：报告参数、结构化缺失文字补填、图表查看；保存只做本地校验，使用稿件哈希防止覆盖其他编辑。人工参数单独保存可追溯工件。内容和图表完整后才开放终审。
