# 本轮修改与验证

本轮采用用户确认的规则：标题加原文梗概向量化，新记录与固定组代表的余弦相似度达到阈值即自动入组，否则建立新组。代表保持为首个成员，不沿成员之间的相似关系串联合并。当前本地实现使用 TF-IDF 词项向量，并非外部语义 embedding。初始试用阈值为 0.65，可在模板确认页配置，尚未按人工同事件标注校准。

## 三个主要确认阶段

1. 两份报告比对后预览模板：固定文字直接展示，动态字段显示标签，点击可查看两份历史示例和修改显示名称。完整 JSON Schema 收在高级详情中。模板确认页保存相似度阈值、重点预警统计范围和 TOP10 排序规则。
2. 数据处理完成后一次整体审核：显示全量、调性、平台统计，自动事件组、成员标题/时间/来源/梗概/原文链接，以及分类与成员。支持将勾选成员移动到另一事件或分类、拆成新事件、应用分类名称。TOP10 预览按收录记录数排序，不冒充没有来源的传播热度。修改在整体确认时保存，用户不必逐组确认。
3. 数据锁定后开始逐槽写作，报告预览展示缺失项。只有完整报告才显示终审入口。数据未确认时，前端禁用写作，后端同时拒绝写作、导出和终审请求。

文件路径和工作表索引会传给数据 Agent。模型要求再次提供已知路径等情况记录为运行诊断，不再生成用户确认项。旧任务可按新规则重新处理，旧的待办被标记为流程已替代，不伪造人工确认，历史日志保留。

运行动态区域仅渲染最近 20 条事件中的简短进展，完整调用参数、结果与错误在日志下载中保留。写作改为后台执行，点击后立即显示正在写作，防止无反馈与重复提交。审核页编辑期间，后台刷新不会重建审核内容。

## 验证证据

- 单元/API 测试覆盖固定代表防串联、梗概参与归并、原始成员覆盖、非法阈值、数据未确认禁止写作、审核必须覆盖全部成员、整体确认后锁定、冻结后拒绝重复审核、模板规则校验和日志分页。
- 真实 10 月全量数据重跑：28,789 行；负面或预警范围 3,914 行；阈值 0.65 自动得到 1,990 个事件。该结果只验证成员保留和规则执行，不代表与人工去重的 817 行一致，也不代表准确率已达到验收目标。测试留下的本期数据仍等待用户审核。
- 隔离浏览器检查：模板标签与历史示例可见、缺少规则不能确认、统计/事件/分类内容可见、成员拆分更新页面、未确认时写作禁用、日志区域有界、页面无 JavaScript 异常。浏览器未提交真实数据确认。

## 保留的限制

两份报告自动提取的字段含义和取数绑定仍属于模板候选，未绑定字段会保留待填。当前结构化 Word 的图表位置尚未全部接入正式绘图，因此可能仍无法终审。界面会展示这些缺失，不能把本轮交互和状态控制的完成等同于整份报告已经通过验收。
