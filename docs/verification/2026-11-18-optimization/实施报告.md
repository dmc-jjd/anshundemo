## 边界与限制

- SQLite 和文件系统无法共享原子提交；本轮保证普通异常回滚，进程被强制终止后仍可能留下未索引的文件。不会自动删除未知残留。
- 队列登记仍使用进程内 BackgroundTasks；进程崩溃或持续数据库故障可能使已领用任务未执行。没有跨重启自动补投或 durable outbox；`report_dispatch` 只是登记状态，不是任务执行成功证明。
- `calculate_metrics` 的声明 Schema 与合法/缺失/跨任务/null/零分母路径已验证；执行器仍未对所有工具参数做完整 JSON Schema 类型验证。
- S5 两个历史哈希失败未迁移基线、未改 xfail/skip，本轮不宣称其已解决。
- 未使用真实客户数据、模型或搜索服务，未正式出稿，未验证 Word 视觉版式。客户提示词、模板和业务阈值未迁移。

实施细节、决策和失败记录见同目录 `progress.md`；前后哈希和 diff 用于后续审阅。
