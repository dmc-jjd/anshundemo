# 星桥约稿演示流程

日期：2026-11-18。

工作台“今日热点话题”右上方新增截图风格的星桥入口。点击后读取热点缓存及微博、抖音、头条、百度四个平台现有热榜，不执行采集。单个列表为空、读取超时或失败时，在选题窗口内补充明确标注的演示选题，不改写首页缓存或现有社媒占位接口。

跨列表只能选择一个话题。确认后访问本机 `/api/starbridge/demo-package`，取回包含模拟原文、网民评论和媒体评论的 JSON 材料包，结合固定约稿提示词写入当前浏览器标签页的 sessionStorage，再转入 KN·AiStudio。组件渲染就绪后，内容填入真正的待发送输入框；已有输入追加保留；成功交接后删除临时交接数据，避免重复粘贴。失败保留交接内容，并提示错误。取消选题不生成交接数据。

材料包链接为本机可访问的演示接口，参数携带选题标题与来源。模型所在服务可能无法访问本机地址，因此输入框同时附上 JSON 材料包，完整演示无需模型读取本机链接。模拟原文、评论及作者均明确标注，不用于正式出版；不声称已接入内部数据口。

提示词文件：`app/static/starbridge-prompt.md`。依据用户提供的盐源县委历史 DOCX，保留“标题、一、事件概述、二、舆论观点”的文章结构，以及主题归纳、观点归因、逐项来源的行文方式。额外要求区分媒体/专家/网民、不补造事实或统计、不预设正面结论、缺失信息列为编校待核事项。历史报告仅作为结构参考，未在线核实其中事件与链接。

未来接入：热点继续遵循 `/api/hotspot` 返回结构；社媒数据源接入 `app/social_hotlist.py` 的 `_fetch_platform()`。星桥选题及材料包调用集中在 `app/static/starbridge.mjs`；真实接口就绪后应替换演示材料包适配点及演示文案，并支持真实原文、评论、来源与采集范围，不可直接把 demo 标记改成真实数据。

验证：

- `scripts/run_scoped_checks.py tests/test_starbridge.py tests/test_hotspot.py`：41 passed；离线隔离，不操作客户数据，不调用模型/搜索。
- `node --test tests/starbridge_handoff.test.mjs`：3 passed；覆盖组件延迟就绪、已有草稿保留、交接只消费一次、格式错误保留、所选标题/链接/提示词/随附材料。
- `scripts/verify_starbridge_browser.py`：隔离 FastAPI 合成服务和临时 Chrome profile，验证实际 Deep Chat 输入框；截图为 `desktop-selection.png`、`mobile-selection.png`、`studio-prefilled.png`，请求与断言见 `browser-result.json`。验证单选、取消、跳转、预填、390px 窄屏窗口，以及无 `/api/chat/stream` 请求。
- 修改文件的 JS 语法和 Git 差异空白检查通过。impeccable 检测提示来自现有页面的字号、对比度和样式，未扩大本次范围修改既有设计。

未执行真实模型生成或正式出版验收；当前交付范围是完整选题与预填演示。未提交、推送或部署。

## 用户验收反馈后的修正

用户反馈跳转后未预填。8765 日志记录了材料包、提示词及 chat.html 成功请求，但没有对应新版 chat-page.js 请求，旧脚本缓存是主要嫌疑，未直接读取用户浏览器缓存，不能视为已证实的唯一根因。首次实现仅用全新 Chrome profile 验证，未覆盖已有用户缓存。

修正：为工作台星桥入口、对话入口、交接模块及跳转 URL 增加版本参数，避免继续复用旧脚本；200ms 和 1200ms 的就绪检查同时重试交接，而非仅设置占位文案。交接消费后不会重复填入。新增版本路由回归测试先失败再通过，Node 测试当前4项通过；真实 Chrome 回归增加已有历史会话及延迟1.5秒后正文仍保留且只出现一次的断言，通过。8765 静态页面和脚本已核实返回新版内容。实际用户浏览器仍需再次选择话题验收。
